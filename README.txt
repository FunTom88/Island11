ISLAND11 0.4.2 — исправление читаемости календаря

1. Полностью выйдите из старого Island11 через значок в трее → «Выход».
2. Распакуйте архив в отдельную папку и запустите Island11.exe.
3. Выберите вкладку «Дата». Позиция панели, настройки и источник плеера сохранятся.
Если автозапуск указывает на старую папку, выключите и снова включите его в меню новой версии.

Календарь: тёмный фон, читаемые числа, зелёная рамка у сегодняшней даты, заливка у выбранной. Стрелки переключают месяцы, кнопка «Сегодня» возвращает текущий месяц и дату. Выбор соседних месяцев в сетке также работает.

Исправления звука версии 0.4.1 сохранены. Ползунок «Звук ПК» управляет общей громкостью Windows, а не громкостью только Spotify. Автоматическое обновление шкалы не должно менять громкость. Звуковое исправление ещё нуждается в проверке на вашем ПК; первопричина предыдущего сбоя не установлена.

Сборка Release и 43 проверки логики прошли, включая расчёт начала недели и високосного года. Реальный внешний вид WPF на Windows в данной среде не проверялся.

В архиве исходники и тесты; для самостоятельной сборки нужен .NET 8 SDK. История буфера хранится локально без шифрования и по умолчанию выключена. Текущие настройки и данные не удаляются автоматически.
